# **Weather App ⛅**  
_A Modern Weather Forecasting Application_  

[Live Preview](https://komal2203.github.io/Weather-App/)  

## 🚀 About the Project  
The Weather App is a **user-friendly weather forecasting application** that provides **real-time weather updates** based on user input. It fetches accurate weather data and displays **temperature, humidity, wind speed, and other weather conditions** in an intuitive UI.  

## ✨ Features  
✅ **Real-time Weather Updates** – Get live weather information for any location  
✅ **Search Functionality** – Enter a city name to fetch weather details instantly  
✅ **Detailed Weather Data** – Displays temperature, humidity, wind speed, and weather conditions  
✅ **Beautiful UI** – Minimalistic and clean interface for an enhanced user experience  

## 🛠 Tech Stack  
🔹 **Frontend:** HTML, CSS, JavaScript  
🔹 **API:** OpenWeatherMap API  
🔹 **Tools & Libraries:** Fetch API, Geolocation API

## 🚀 Getting Started  

### **Prerequisites**  
Make sure you have a working internet connection and a valid API key from **OpenWeatherMap**.  

### **Installation**  

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/your-username/Weather-App.git
   cd Weather-App
   ```  

2. **Set Up Environment Variables**  
   Open the `script.js` file and replace `YOUR_API_KEY` with your OpenWeatherMap API key:  
   ```js
   const apiKey = "YOUR_API_KEY";
   ```

3. **Open in Browser**  
   Simply open the `index.html` file in your browser to use the app.
